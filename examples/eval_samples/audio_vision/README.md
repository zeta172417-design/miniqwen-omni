# audio_vision

## 输入

- 语音问题：`input_audio.wav`
- 输入图像：`input_image.jpg`

语音问题的完整文字内容：

```text

B. ten
C. four
D. one
Answer with only the option letter.
```

```text
The number of people visible in the picture is 4.
```
